## ⚡ Execution Commands

Run any of the following commands from `c:\Users\minal\Project\AIML-Forum`:

```bash
# Run the master growth orchestrator
npm start

# Run the Content Curator agent (Seeds anchor transition guides)
npm run curate

# Run the Outreach Scout agent (Social listening & targeted Q&A response)
npm run outreach

# Run the Community Nurture agent (Personalized member onboarding)
npm run nurture
```
